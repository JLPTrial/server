# Módulo do servidor

Este módulo é dedicado apenas ao backend do JLPTrial que está sob a mesma licença do projeto maior.

O servidor, construído utizando `FastAPI` + `SQLModel` + `SQLite`, é responsável por controlar e sincronizar as interações do usuário tanto da aplicação mobile quanto da aplicação WEB.

Qualquer dúvida que você possa vir a ter, poderá ser consultada verificando a [documentação do repositório principal](https://github.com/JLPTrial/JLPTrial)

## Como compilar este aplicativo

Para simplificar a build, dado que esta precisa de algumas configurações extras com respeito as variáveis de ambiente, sua inicialização foi implementada através do devbox, sugiro que leia o [guia de setup](https://github.com/JLPTrial/JLPTrial/blob/main/docs/SETUP.MD) disponível no repositório principal.
